# Onechip-for-12F629
Port of the Onechip code to the 12F629 MCU

Porting of the old Onechip mod (made for the SCPH-102) for the 12c508 MCU to the "newer" 12f629 mcu.

Stealth + BIOS patching supported.
conf word:0x3FC4 

For installation, follow the wiring diagrams in the Install folder based on your console motherboard.
