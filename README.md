# Onechip-for-12F629
Porting of the Onechip code to the 12F629 MCU

Porting of the old Onechip mod (coded for the SCPH-102) originally made for the 12c508 MCU to the "newer" 12f629 mcu.

Stealth + BIOS patching supported.

Conf word:0x3FC4 

For installation, follow the wiring diagrams in the Install folder based on your console motherboard.
